# Execute start without a Start Plan

Start clients call the Gateway Module start operation directly without a separate read-only Start Plan. An attempt without sufficient PAC Replacement Consent returns structured consent detail without mutating; the caller renders that decision and retries with consent bound to the foreign PAC state it displayed. The consent fingerprint is derived from sorted network-service name and foreign PAC URL pairs, excluding enabled flags and owned or empty entries. Every attempt reassesses current PAC state before mutation, and a changed URL or newly present foreign PAC requires fresh consent. This removes a redundant normal-start PAC inspection and keeps the Gateway Module interface narrow, at the cost of dropping the read-only `GET /start/plan` preview operation and carrying a PAC-state fingerprint on consent-bearing retries.

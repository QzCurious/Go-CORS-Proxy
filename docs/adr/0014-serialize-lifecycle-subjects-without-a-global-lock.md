# Serialize lifecycle subjects without a global lock

Gateway lifecycle concurrency is coordinated by the state each operation owns rather than one global mutation mutex. A non-blocking, process-lifetime, OS-backed Gateway Ownership Lease admits one owner before verification, cleanup, and cache publication; the Gateway State Cache remains discovery data and is not continuously watched as an ownership signal. Single-Flight Start rejects a competing Start Sequence; a cross-process CA Mutation Lease serializes CA Ensure, replacement, uninstall, and cancellation reconciliation but is released before PAC work; and each Managed PAC Session serializes install, refresh, reconciliation, and reattachment. Ownership contenders fail immediately for explicit user retry, CA lease contenders wait cancellably and then reinspect state, and concurrent starts return `start-already-mutating`.

Stop and fatal runtime failure have cancellation precedence over start and PAC work. Once stop takes precedence, the owner enters Owner Ending and remains teardown-only through any Retryable Stop Failure; late starts return `stop-cancelled`, status reports `ending`, and stop may be retried until success or process exit. Ending closes the Managed PAC mutation sequence, waits for in-flight PAC mutation and CA cancellation reconciliation to settle, and only then runs Gateway Footprint Cleanup, so no platform write can occur after cleanup. A stop-preempted caller receives a structured `stop-cancelled` start outcome carrying any completed CA result rather than a generic context error. Status remains read-only and reports an admitting runtime as `starting`; external PAC changes remain outside process coordination and are reconciled at the explicit boundaries defined by the Managed PAC Lease.

Trusted Runtime Admission is the CA handoff barrier: an admitting trusted runtime holds the Active Trusted Runtime CA Guard, adopts the currently usable Installed User CA before traffic, and either begins serving with that identity or withdraws. There is no runtime CA rotation and no cross-command lock held for the duration of start.

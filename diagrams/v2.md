## Setup

```mermaid
flowchart TD
  User[使用者]
  SeamlessCors[seamless-cors]
  UpstreamList[Upstream List]
  SystemPAC[系統 PAC 設定]

  User -->|設定要導流的 upstream| UpstreamList
  User -->|start| SeamlessCors
  SeamlessCors -->|讀取| UpstreamList
  SeamlessCors -->|提供 PAC URL| User
  User -->|貼上 PAC URL| SystemPAC
```

## PAC Flow

```mermaid
sequenceDiagram
  participant Browser
  participant SystemPAC as 系統 PAC 設定
  participant UpstreamList as Upstream List
  box seamless-cors
    participant Gateway
    participant PacEndpoint as PAC Endpoint
  end

  Browser->>SystemPAC: 讀取已安裝 PAC URL
  Browser->>PacEndpoint: 取得 PAC
  PacEndpoint->>Gateway: 要求 PAC
  Gateway->>UpstreamList: 讀取 Upstream List
  Gateway-->>PacEndpoint: 產生 PAC
  PacEndpoint-->>Browser: 回傳 PAC
```

## PAC Routing Flow

```mermaid
sequenceDiagram
  participant Browser
  participant GeneratedPAC as Generated PAC
  box seamless-cors
    participant CorsProxy as CORS Proxy
  end
  participant Upstream as Upstream API

  Browser->>GeneratedPAC: 依 PAC 判斷 request upstream
  alt PAC 回傳 DIRECT
    Browser->>Upstream: 直接送出 request
    Upstream-->>Browser: 原始 response
  else PAC 回傳 PROXY
    Browser->>CorsProxy: HTTP request
    CorsProxy->>Upstream: 轉送 request
    Upstream-->>CorsProxy: upstream response
    CorsProxy-->>Browser: 修補後 response
  end
```

## Preflight Flow

```mermaid
sequenceDiagram

  CorsProxy-->>Browser: 直接回應 preflight
```

## Request Flow

```mermaid
sequenceDiagram
  participant Browser
  box seamless-cors
    participant CorsProxy as CORS Proxy
  end
  participant Upstream as Upstream API

  Browser->>CorsProxy: 實際 request
  CorsProxy->>Upstream: 轉送 request
  Upstream-->>CorsProxy: upstream response
  CorsProxy->>CorsProxy: 修補 CORS headers
  CorsProxy-->>Browser: 回應修補後的 response
```
